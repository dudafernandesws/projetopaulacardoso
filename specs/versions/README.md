# Versões

Este diretório contém um manifesto por versão do projeto.

## Convenção

- Nome do diretório: `vMAJOR.MINOR.PATCH`.
- Arquivo obrigatório: `README.md` baseado em `specs/templates/release-template.md`.
- Uma spec só entra na versão quando estiver `verified`.
- Após publicação, registrar data e commit ou tag.
- O manifesto referencia specs em `specs/changes/`; não duplica nem move seus arquivos.
- Correção posterior recebe nova spec e nova versão.
